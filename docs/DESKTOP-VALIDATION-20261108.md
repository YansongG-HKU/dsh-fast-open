## 结果与范围

真实 Electron、同一 desktop profile、同一大会话，交替 OFF/ON 三轮；每轮正常退出并重启，保留渲染缓存。开关仅更改 bundle 条目，最后恢复原配置。测量以侧边栏点击到目标标题及新正文可读取为终点，100ms 轮询；不是首次绘制时间，也不是所有离屏内容布局完成时间。

模型运行测试：新建测试会话，要求仅执行 60 秒终端等待。检测到停止生成按钮后切换：

- 已打开过的大会话：1141 ms；
- 本实例尚未打开的另一大会话：48844 ms，期间实际观察到“载入历史…”；显示正文后测试会话仍标记为进行中。

因此 CSS 优化没有修复原始运行中长等待。尚不能唯一归因于 Electron 渲染、后台节流、历史订阅或插件。第二次测试未成功进入模型运行状态，作废，不计入样本。测试草稿已清除。

## 已修复的安装缺陷（v1.1.1）

真实 desktop junction 曾指向 `dsh-fast-open/scripts`，而包根目录才包含 package.json。安装 CLI 省略 pluginDir 时错误默认到 scripts，导致 Host 曾显示已加载但重启后客户端无样式。

修复：默认路径改为脚本上一级；修改 profile 前校验包名及 client.js。补充 CLI 省略参数的真实 junction 回归，以及无效路径不写入 profile 的测试。修复 desktop junction 后通过重新启动和真实 DOM 计算样式确认生效。
